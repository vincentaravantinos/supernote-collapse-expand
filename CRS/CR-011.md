# CR-011: Name confirmation dialog branded as Collapse / Expand

**Status:** Done

## Request

The confirmation dialog shown when setting/replacing a section's name is
titled "Prompt" (fixed by the SDK's `showRattaDialog`, which takes no
title). The user can't tell it comes from this plugin. Replace it with the
plugin's own dialog, titled "Collapse / Expand" (user chose this over
prefixing the message text).

## Impact analysis

**High impact — escalate to Feature.** New user-facing UI: a confirm
dialog rendered in the plugin's own view (App.tsx, which today only shows
the "Working…" card), a new promise-based bridge from the Name action to
it, and interplay with the busy view it would share. Adds a requirement.
