# CR-013: Menu button as the entry point for secondary actions

**Status:** Done

## Request

Paradigm shift: a finger tap on the icon is the main way to expand/collapse;
the lasso-menu button serves the less frequent actions (initial Collapse,
naming, multi-section). Minimize taps: if only one action applies to the
selection, run it without asking; if several do, ask. When several sections
of mixed state are selected, offer "expand everything" (and its counterpart)
instead of silently giving Recollapse priority.

## Impact analysis

**High impact — escalate to Feature** (handled in the same Feature pass as
CR-011/CR-012). Changes the button's selection classification and the
Expand/Recollapse triggers in SPEC.md; reuses the plugin-view dialog from
CR-011.
