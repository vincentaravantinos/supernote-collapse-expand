# CR-001: Upgrade sn-plugin-lib

**Status:** Done

## Request

Update `collapse_expand`'s `sn-plugin-lib` dependency (currently pinned
`^0.1.43`) to the latest version, per the Chauvet 3.29.43 Beta
(Manta/Nomad) / 2.26.40 Beta (A5X/A6X) plugin preview release.

Without this, the plugin will not run at all on the new firmware (the
release notes state plugins on old dependency versions are refused).

Source: r/Supernote_dev, "Plugin Preview Build: Chauvet 3.29.43 Beta for
Manta / Nomad and Chauvet 2.26.40 Beta for A5X / A6X" (u/Dunn-sn).

## Impact analysis

**Low impact — fast-track.** Mechanical dependency bump, single
well-understood change (matching Scribble's precedent: `npm install
sn-plugin-lib@latest`, keeping this repo's tracked `package-lock.json`
rather than switching to yarn). No new requirements or design decisions
by itself — the permission-declaration design work this release also
requires is split out to CR-002.
