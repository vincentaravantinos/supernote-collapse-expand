# CR-012: Name a section while it's expanded

**Status:** Done

## Request

Naming currently only works on a collapsed section. User's rule: when the
button is pressed and the selection contains a section's icon (collapsed
or expanded) plus strokes that belong to no section, treat those strokes
as a name.

## Impact analysis

**High impact — escalate to Feature.** Changes the selection
classification in the button handler, and overlaps an existing
requirement: an expanded section's icon + new ink currently means
Recollapse (absorbing ink drawn inside the area, REQ-200). SPEC.md's Name
section explicitly lists this as out of scope today.
